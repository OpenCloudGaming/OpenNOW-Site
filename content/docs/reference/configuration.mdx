OpenNOW persists user settings as JSON in the OpenNOW data directory as `settings.json`. The Rust core owns load, migration, normalization, and save. Qt Settings pages edit those values over the shell/core protocol.

<Callout type="info" title="Qt defaults differ from Electron">
Desktop streaming defaults to native NVST (`streamClientMode: "native"`, `transportMode: "nvst"`). There is no web streamer setting to return to in the Qt app.
</Callout>

## File locations

<LocalDataLocationsTable pathHeader="Path" />

Override the data directory with `OPENNOW_DATA_DIR` when needed. Diagnostics live under `diagnostics/` inside that directory.

## Video and stream

| Setting | Type | Default | Description |
| --- | --- | --- | --- |
| `resolution` | `string` | `"1920x1080"` | Stream resolution |
| `aspectRatio` | `string` | `"16:9"` | Aspect-ratio preference |
| `fps` | `number` | `60` | Target frame rate |
| `maxBitrateMbps` | `number` | `75` | Maximum stream bitrate in Mbps |
| `codec` | `string` | `"auto"` | Stream codec preference |
| `fallbackCodec` | `string` | `"auto"` | Bounded fallback when the preferred codec cannot produce video |
| `colorQuality` | `string` | `"8bit_420"` | Bit-depth/chroma preference |
| `streamClientMode` | `string` | `"native"` | Desktop streaming mode |
| `transportMode` | `string` | `"nvst"` | Native media transport |
| `nativeVideoBackend` | `string` | `"auto"` | Platform video/API preference |
| `audioOutputDevice` | `string` | `""` | Opaque audio output ID; empty means system default |
| `windowsGpuDeviceId` | `string` | `""` | Windows GPU device selection |
| `enableHdr` | `boolean` | `false` | HDR preference |
| `upscaling` | `string` | `"off"` | Spatial upscaling: `off`, macOS `metalfx`, or Windows/Linux `fsr1` |
| `upscalingSharpness` | `number` | `10` | Clarity 0–15 when upscaling is enabled (MetalFX sharpening before upscale; FSR 1 after) |
| `upscalingDenoise` | `number` | `0` | Noise reduction 0–20 before MetalFX on macOS; unused for FSR 1 |
| `frameGeneration` | `string` | `"off"` | Frame-generation preference |
| `region` | `string` | `""` | Preferred region URL; empty means auto |
| `sessionProxyEnabled` | `boolean` | `false` | Use an explicit proxy for session/signaling traffic |
| `sessionProxyUrl` | `string` | `""` | Proxy URL when enabled |
| `enableL4S` | `boolean` | `false` | Request L4S behavior where supported |
| `enableCloudGsync` | `boolean` | `false` | Cloud G-Sync/VRR preference |
| `identifyAsSteamDeck` | `boolean` | `false` | Advertise Steam Deck-style client identity where NVIDIA allows it |
| `enablePersistingInGameSettings` | `boolean` | `true` | Keep in-game graphics settings between sessions for supported games and memberships (applies to new sessions) |
| `muteWhenOutOfFocus` | `boolean` | `false` | Mute stream audio while OpenNOW is in the background |
| `backgroundStreamReminder` | `boolean` | `false` | Request taskbar/dock attention every 5 minutes while a stream runs in the background |
| `suppressTenBitWarning` | `boolean` | `false` | Hide the one-time 10-bit color stuttering warning after dismissal |

## Capture and recording

| Setting | Type | Default | Description |
| --- | --- | --- | --- |
| `recordingBitrateMbps` | `number \| null` | `null` | Recording bitrate in Mbps; `null` leaves selection automatic |
| `recordingResolution` | `string` | `"720p"` | Local recording capture height |
| `recordingFps` | `number` | `30` | Local recording frame rate |
| `replayBufferEnabled` | `boolean` | `false` | Replay-buffer preference |
| `replayBufferSeconds` | `number` | `30` | Replay-buffer length |
| `replayBufferMemoryMiB` | `number` | `256` | Replay-buffer memory budget |

Recordings are written as Matroska (`.mkv`) under the OpenNOW Pictures media root. See [Media](/docs/reference/media/).

## Diagnostics

Use **Settings → About → Copy diagnostics** for a bounded redacted export. Do not post credentials, tokens, or unredacted account details to public issues.
