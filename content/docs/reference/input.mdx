OpenNOW captures gameplay input in the Qt desktop app and sends it through the in-process native streamer. Desktop and console shells share the same input preferences; console mode changes browsing/navigation, not NVIDIA account state.

## Default shortcuts

| Shortcut | Action |
| --- | --- |
| `Ctrl+N` | Cycle stats HUD |
| `F8` | Toggle pointer lock |
| `F11` | Toggle fullscreen |
| `Ctrl+F11` | Take screenshot |
| `F12` | Start/stop recording |
| `Ctrl+F12` | Save clip / replay action |
| `Ctrl+Shift+Q` | Stop session |
| `Ctrl+Shift+K` | Toggle anti-AFK |
| `Ctrl+Shift+M` | Toggle microphone |

All shortcuts can be changed in Settings. On macOS the UI may display modifier labels differently while the stored binding uses the same setting string.

`allowEscapeToExitFullscreen` defaults to `false`. Escape is still used for pointer-lock release behavior; opting into Escape fullscreen exit makes fullscreen easier to leave but can conflict with in-game Escape usage.

## Keyboard

Choose **Settings → Controls → Keyboard layout** (desktop and console share one list). The control matches your physical keyboard and is sent to GeForce NOW when a session starts. The setting key is `keyboardLayout` (default `"en-US"`).

The layout is stored in the session snapshot at session start. Editing preferences mid-session does not remap an active stream — restart or resume the session after changing it.

### Platform behavior

| Platform | Behavior |
| --- | --- |
| Linux (X11 / Wayland) | Gameplay keys map from physical key positions to the selected regional Windows layout, including AltGr / right-Alt. AltGr must not trigger local shortcuts. |
| Windows | Continues to use native virtual keys. |
| macOS | Logical-key path is unchanged. |

Chinese layouts (`zh-CN`, `zh-TW`) provide physical keys for the remote IME; they do not transmit locally composed IME text. Unsupported as separate choices: Dvorak, Turkish F, French BÉPO, and similar alternatives.

## Pointer lock and mouse

- Pointer lock captures the cursor inside the stream view. Toggle with `F8` by default.
- `mouseSensitivity` defaults to `1` and scales relative movement.
- `mouseAcceleration` defaults to `1`.
- On macOS, relative mouse mode uses native CoreGraphics pointer capture rather than repeated cursor warps. Unlocked absolute mode can allow the pointer to leave the window.

## Gamepad

OpenNOW uses SDL3 for controller discovery and input. Stick dead zones default to **5%** for both sticks (0–50) and vibration intensity is configurable. Controllers can drive the console shell's focus navigation.

| Setting | Description |
| --- | --- |
| `controllerMode` | Controller-oriented shell preference |
| `launchInConsoleMode` | Start in console/TV-oriented shell |
| `switchToConsoleOnPad` | Automatically switch to console when a pad connects |
| `leaveConsoleOnPointer` | Leave console shell on pointer interaction |
| `consoleProfilePickerOnLaunch` | Show Who's playing? when console mode starts |
| `autoFullScreen` | Auto-enter fullscreen when console flows request it |
| `controllerLeftStickDeadzone` / `controllerRightStickDeadzone` | Stick dead zones |
| `controllerVibrationIntensity` | Rumble intensity |

## Clipboard paste

Settings → Controls → **Clipboard paste** enables local-to-stream plain-text paste while streaming. The native path submits text through the streamer FFI rather than converting every paste into keystrokes when the typed clipboard path is available.

## Microphone

| Mode | Behavior |
| --- | --- |
| `disabled` | No microphone capture |
| `push-to-talk` | Hold/toggle the configured microphone shortcut to transmit |
| `voice-activity` | Exposed as continuous open-microphone style capture when enabled |

Grant OS microphone permission, select the intended mode, and reconnect the stream after changing capture settings. Live acceptance should confirm remote voice reception and uninterrupted game audio.
