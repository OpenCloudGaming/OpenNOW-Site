OpenNOW captures screenshots and records the source stream through the native desktop path. Media is listed in the app's Media UI. Recordings are written as Matroska (`.mkv`) files with optional JPEG thumbnails.

## Storage locations

<LocalDataLocationsTable variant="media" />

## Screenshots

- Triggered by the screenshot shortcut (default `Ctrl+F11`) or stream/Media controls.
- Written under `Pictures/OpenNOW/Screenshots/` unless `OPENNOW_PICTURES_DIR` overrides the Pictures root.
- Supported extensions include PNG, JPG/JPEG, and WebP.

## Recordings

- Triggered by the recording shortcut (default `F12`) or stream/Media controls.
- Native recordings target a new `.mkv` file under `Pictures/OpenNOW/Recordings/`.
- Recording bitrate, resolution, and FPS preferences live in Settings (`recordingBitrateMbps`, `recordingResolution`, `recordingFps`).
- Replay-buffer related preferences also exist in settings when the feature is enabled.

## Media listing

- Screenshots and recordings can be listed together and filtered by game where metadata is available.
- Recording thumbnails use a companion `-thumb.jpg` when present.
- Media can be revealed in the system file manager or deleted from the app.

## Capture flow

```text
Qt shell / shortcuts          Native streamer + core media helpers
   │                                  │
   ├─ screenshot request ────────────►│── write image under Screenshots/
   │                                  │
   ├─ start/stop recording ──────────►│── write Matroska under Recordings/
   │◄── gallery listing ──────────────┤
```
