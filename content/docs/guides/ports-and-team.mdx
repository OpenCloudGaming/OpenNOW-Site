OpenNOW started as a desktop client and now runs on phones, handhelds, and consoles. Most ports are separate projects with their own repository, release schedule, and maintainer. This page lists each one with its status, source, download, and the minimum hardware its repository states.

<Callout type="info" title="Independent community projects">
None of these ports are affiliated with NVIDIA, Sony, Nintendo, Apple, or Google. Every port needs your own GeForce NOW account. Console and handheld ports run as homebrew.
</Callout>

## Status levels

| Status | Meaning |
| --- | --- |
| **Stable** | Published as a stable release and recommended for everyday play. |
| **Beta** | Published builds you can install today. Expect rough edges and fast-moving changes. |
| **Experimental** | A working prototype, or code without a published build. Expect bugs and missing features. |
| **Coming soon** | Announced and in development. No release has been published yet. |

## About each port

**Desktop.** The Qt Quick app with the in-process native streamer. [Getting Started](/docs/guides/getting-started) covers every package, and [Troubleshooting](/docs/guides/troubleshooting) covers common problems.

**Raspberry Pi 4/5.** The desktop app's Linux ARM64 build. Pi 4 decodes H.264 and HEVC in hardware. Pi 5 decodes HEVC in hardware and has no H.264 hardware decoder. Both decoder paths support 8-bit 4:2:0 SDR only. For a first check, select the V4L2 backend, HEVC, 8-bit 4:2:0, HDR off, and 1920×1080 at 60 FPS. The upstream guide still lists the per-board acceptance matrix that must pass before Pi support counts as hardware-validated.

**OpenNOW Mac.** A separate native SwiftUI client with its own NVST transport, upscaling, ultrawide modes, and Steam Controller support. The README credits [Jayian1890](https://github.com/Jayian1890) for the base and core functionality.

**Android and iOS.** The Android app ships on Google Play, with a direct beta APK for previews. The iOS app is in beta on TestFlight.

**Nintendo Switch.** A native Borealis homebrew client derived from [SwitchNOW](https://github.com/Blade-Punisher/SwitchNOW) by Blade-Punisher. Follow the [Nintendo Switch guide](/docs/guides/nintendo-switch) to install it.

**PlayStation 5.** A console-tested experimental alpha with hardware H.264 and HEVC Main10 decoding, GPU presentation, DualSense input, and an in-game keyboard. It is not a retail PlayStation application. [Portablelle](https://github.com/Portablelle) created the original PS5 port that this project continues.

**PS Vita.** A native Rust homebrew client that uses the Vita's hardware H.264 decoder. josephinoo also maintains [rtc-vita](https://github.com/josephinoo/rtc-vita), a fork of the webrtc-rs `rtc` stack with PS Vita network-interface support and a direct H.264 path.

**DualScreen.** On handhelds with a second built-in screen, OpenNOW runs a companion deck on the bottom screen: account and hours, search, presets, the queue, live stream statistics, a touch keyboard, and a trackpad. It turns on only when the second screen is built in. It lives on a development branch and has no published build yet.

**4Handhelds.** A controller UI that runs the OpenNOW core and native streamer on RK3326 handhelds, with Rockchip MPP video decoding. Its first release is a beta for dArkOS on an R36S-class handheld: extract it into the ports folder and launch OpenNOW from the device.
