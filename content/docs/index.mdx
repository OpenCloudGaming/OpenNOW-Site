OpenNOW is an open-source GeForce NOW client. The desktop app uses Qt Quick for the interface and Rust for account services and streaming. Desktop and controller-first console layouts live in the same app. Separate Android, iOS, and [OpenNOW-Switch](/docs/guides/nintendo-switch) builds are available for other platforms.

For macOS users looking for a separate performance-focused build, Jayian1890 maintains [OpenNOW-Mac](https://github.com/OpenCloudGaming/OpenNOW-Mac).

<Callout type="info" title="Independent community project">
OpenNOW is not affiliated with NVIDIA. NVIDIA and GeForce NOW are trademarks of NVIDIA Corporation.
</Callout>

<Callout type="info" title="Desktop is Qt/native">
OpenNOW's desktop client on `main` uses Qt Quick and an in-process native NVST streamer. It replaces the retired Electron/`opennow-stable` app and has no Chromium/WebRTC fallback. See the [announcement post](https://x.com/Zortosdev/status/2093023076191440963) for a first look.
</Callout>

<Callout type="info" title="Published packages vs source on main">
The GitHub Latest release is **v1.0.1** (`OpenNOW-Qt-1.0.1-…` packages, published 2026-09-13). Download stable builds from [Releases](https://github.com/OpenCloudGaming/OpenNOW/releases/latest) or the [download picker](/#downloads). Use Qt nightlies / artifacts from a successful [`qt-ci` run on `dev`](https://github.com/OpenCloudGaming/OpenNOW/actions/workflows/qt-ci.yml?query=branch%3Adev) when you need post-1.0.1 changes. **v1.0.0** remains available as a historical release. Historical tags such as v0.5.5 may still contain Electron packages.
</Callout>

## Fast path

<Steps>
  <Step>
    **Download** an `OpenNOW-Qt-…` package from the [OpenNOW download picker](/#downloads) or [GitHub Releases](https://github.com/OpenCloudGaming/OpenNOW/releases).
  </Step>
  <Step>
    **Install** the artifact for your platform: Windows `.msi` or portable `.zip`, Linux `.AppImage` (recommended), `.deb`, or an optional Flatpak build, macOS Apple Silicon `.dmg`. Android, Nintendo Switch, and iOS remain separate projects.
  </Step>
  <Step>
    **Sign in** through browser OAuth or QR/device authorization and let OpenNOW persist the session locally.
  </Step>
  <Step>
    **Tune** codec, resolution, FPS, bitrate, color quality, region, input, microphone, and capture settings. Switch between desktop and console layouts in the same app.
  </Step>
</Steps>

## What is stable?

<Accordions type="single">
  <Accordion title="Default streaming path">
    The Qt desktop app streams through the in-process native NVST streamer. There is no Chromium/WebRTC fallback in the Qt app.
  </Accordion>
  <Accordion title="Desktop UI">
    Desktop (keyboard/mouse) and console (controller-first) layouts live in the same Qt application.
  </Accordion>
  <Accordion title="Session state">
    OAuth, token refresh, provider behavior, CloudMatch session lifecycle, settings, and diagnostics are owned by the out-of-process Rust core. Qt talks to it over a versioned JSON protocol.
  </Accordion>
  <Accordion title="Published binaries">
    Treat GitHub package names and release notes as the source of truth. Look for `OpenNOW-Qt-…` assets. Older Electron packages may still appear on historical tags such as v0.5.5.
  </Accordion>
</Accordions>
